## Core Concept: WithRedux HOC

**Single wrapper provides both state and dispatch to components and lifecycle hooks.**

```typescript
// Basic usage
WithRedux(WithReactComponent(Route))({
  name: 'dashboard',
  path: '/dashboard',
  store,
  component: DashboardComponent, // Receives { state, dispatch } props
  beforeMount: async ({ state, dispatch }) => {
    if (!state.auth.isAuthenticated) {
      await router.goTo('/login');
    }
    dispatch(loadData());
  },
});

// Standalone (no component)
WithRedux(Route)({
  store,
  beforeMount: async ({ state, dispatch }) => {
    dispatch(initializeApp());
  },
});
```

### Key Features

- Uses React 18's `useSyncExternalStore` for optimal performance
- Type-safe: store types automatically inferred
- Lifecycle hooks receive `{ state, dispatch }` object parameter
- Framework-agnostic (works with any component system)

## Patterns to Follow

## Anti-Patterns to Avoid

| Don't | Do Instead |
|-------|------------|
| Use `{}` type | Use `Record<string, unknown>` |
| Use separate parameters `(state, dispatch)` | Use object `{ state, dispatch }` |
| Create multiple store subscriptions | Use single `WithRedux` wrapper |
