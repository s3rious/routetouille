# No-Framework Example

> Vanilla JavaScript example demonstrating Routetouille without any UI framework.

- `npm run serve`: Start http-server on port 8080
- `npm run dev`: Build and serve

## Core Pattern

**Routes render via `afterMount` hooks with direct DOM manipulation:**

```javascript
import { Router, Route, FallbackRoute, BrowserHistory } from 'routetouille';

const router = Router({ history: BrowserHistory() });

router.root = Route({
  name: 'main',
  path: '/',
  afterMount: () => {
    document.getElementById('root').innerHTML = `
      <h1>Home</h1>
      <nav><a href="/about/">About</a></nav>
    `;
  },
  children: [
    Route({
      name: 'about',
      path: 'about/',
      afterMount: () => {
        document.getElementById('root').innerHTML = `<h1>About</h1>`;
      },
    }),
    FallbackRoute({
      name: '404',
      afterMount: () => {
        document.getElementById('root').innerHTML = `<h1>404</h1>`;
      },
    }),
  ],
});

router.init();
```

## Key Concepts

- **No virtual DOM**: Direct `innerHTML` manipulation
- **Standard links**: Regular `<a href>` tags work automatically
- **Lifecycle hooks**: Use `afterMount` for rendering, `beforeMount` for guards
- **FallbackRoute**: Handles 404 errors

## Anti-Patterns to Avoid

| Don't | Do Instead |
|-------|------------|
| Use framework-specific patterns | Keep it vanilla JS |
| Add unnecessary dependencies | Only routetouille needed |
| Complex state management | Simple DOM updates in hooks |
