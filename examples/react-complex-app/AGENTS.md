# React Complex App Example

> Production-ready React app with domain-driven design, Effector state, and Routetouille.

## Bash Commands

- `npm run dev`: Start Vite dev server
- `npm run dev:api`: Start mock API on port 3001
- `npm run dev:all`: Start both servers
- `npm run build`: Production build
- `npm run lint`: Lint with Biome
- `npm run format`: Format with Biome
- `npm run test`: Run Vitest tests
- `npm run palettier`: Generate CSS design tokens

## Tech Stack

- **Language**: TypeScript (strict mode)
- **Framework**: React 19 + Vite
- **State**: Effector with effector-storage
- **Routing**: Routetouille + react-routetouille
- **Styling**: CSS Modules + design tokens
- **Testing**: Vitest

## Route Composition Pattern

```typescript
export function getExampleRoute(
  router: RouterInterface,
  children: RouteInterface[] = [],
): RouteInterface {
  return WithReactComponent(Route)({
    name: 'example',
    path: 'example/',
    component: ExampleComponent,
    children,
  });
}

// Composed in src/index.ts
router.root = getRootRoute(router, [

    ]),
    getNonAuthRoute(router, [
      getLoginRoute(router),
    ]),
  ]),
  getFallbackRoute(router),
]);
```

## Effector Patterns

```typescript
// Store
const $client = createStore(new ClientModel({}))
  .on(fetchClient.doneData, (_, data) => new ClientModel(data))
  .reset(logOut);

// Effect
const fetchClient = createEffect(async ({ token }) => {
  const res = await fetch('/api/client', {
    headers: { Authorization: `Bearer ${token}` },
  });
  return res.json();
});

// Testing with fork
const scope = fork();
await allSettled(fetchClient, { scope, params: { token: 'test' } });
expect(scope.getState($client)).toEqual(expected);
```

## Anti-Patterns to Avoid

| Don't | Do Instead |
|-------|------------|
| Mix domains | Keep domain boundaries clear |
| Skip TypeScript | Full type coverage required |
| Hardcode API URLs | Use services/api abstraction |
| Skip Effector fork in tests | Always use `fork()` + `allSettled()` |
